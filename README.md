Gerador de Senha

Um site simples e intuitivo para gerar senhas aleatórias com o número de caracteres que você escolher.

✨ Funcionalidades Gera senhas aleatórias com a quantidade exata de caracteres. Interface limpa e responsiva.

Fácil de usar.

🚀 Tecnologias Usadas HTML5 CSS3 JavaScript (com geração de senhas aleatórias) 🛠 Como usar Abra o site no seu navegador. Digite o número de caracteres que deseja na senha. Clique em "Gerar Senha".

A senha será exibida de forma segura na tela. 📂 Estrutura do projeto

index.html: Estrutura da página. style.css: Estilização visual. script.js: Lógica da geração de senhas.
